# ⚽ AI VAR: Football Offside Detection

Simple Computer Vision project using **YOLO11** and dataset `Offside Football.v1i.yolo26`.

---

## 🚀 How to Run in Google Colab (4 Simple Steps)

1. **Upload Notebook:**
   - Go to [Google Colab](https://colab.research.google.com/) and upload `Offside_VAR_System_Colab.ipynb`.

2. **Select GPU:**
   - Click `Runtime` ➔ `Change runtime type` ➔ Select **T4 GPU** ➔ `Save`.

3. **Upload Dataset:**
   - Click the **📁 (Files)** icon on the left panel.
   - Upload `Offside Football.v1i.yolo26.zip`.

4. **Run All Cells:**
   - Press `Shift + Enter` on each cell.
   - **Step 4** will give you a public **`https://xxxx.gradio.live`** link for assignment submission and live demo!

---
